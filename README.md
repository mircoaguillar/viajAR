# ViajAR

ViajAR es una plataforma web orientada a la gestión integral de servicios turísticos. Permite administrar reservas de hoteles, transporte y tours dentro de un mismo sistema, integrando además funcionalidades de gestión de usuarios, carrito de compras y paneles administrativos.

El proyecto fue desarrollado como trabajo integrador de la **Tecnicatura Superior en Desarrollo de Software**, con foco en aplicar conceptos de análisis, diseño y desarrollo de sistemas sobre un caso de uso completo.

## Funcionalidades principales

* Registro e inicio de sesión de usuarios.
* Gestión de reservas de hospedajes, transportes y tours.
* Carrito de compras para consolidar servicios antes de confirmar la reserva.
* Paneles administrativos para la gestión de información del sistema.
* Gestión de usuarios con distintos perfiles.
* Administración de servicios turísticos y disponibilidad.
* Flujo de reservas centralizado en una única plataforma.
* Arquitectura MVC para la organización del proyecto.

## Roles disponibles

El sistema contempla distintos tipos de usuarios según el servicio o nivel de administración:

* **Administrador**
* **Usuario de hospedaje**
* **Usuario de transporte**
* **Usuario de tours**

## Estructura general del proyecto

```bash
viajar/
├── controllers/
├── models/
├── views/
├── assets/
└── index.php
```

* **controllers/**: lógica de control de la aplicación.
* **models/**: acceso y manipulación de datos.
* **views/**: vistas del sistema.
* **assets/**: recursos estáticos del frontend.
* **index.php**: punto de entrada principal de la aplicación.

## Contexto del proyecto

ViajAR fue desarrollado como proyecto integrador académico, con el objetivo de construir una solución web completa para la administración de servicios turísticos, aplicando conceptos de arquitectura MVC, bases de datos relacionales, programación web y organización modular del sistema.
